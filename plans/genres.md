# Жанры релиза, артиста и лейбла

Источник — предсказания `genre_discogs400` (400 стилей Discogs на трек). Реализация —
`app/genres.py` (методика) и `app/store/genres.py` (кэш `release_genres`).

## Как работает модель

Трек режется на куски, по каждому discogs-effnet считает эмбеддинг, голова genre_discogs400
даёт 400 независимых оценок; оценки кусков усредняются. Обучали на стилях **релизов** Discogs,
приписанных каждому треку: оценка — «насколько вероятно, что редакторы Discogs пометили бы
релиз с таким звуком этим стилем». Отсюда:

- оценки разных стилей несравнимы: Techno 0.38 — верхние 10% библиотеки, Tech House 0.38 —
  верхний 1%;
- стили, которые на Discogs ставят вместе, подтягивают друг друга (DnB ↔ Halftime);
- стиля Neurofunk в модели нет — нейрофанк она описывает как Drum n Bass + Halftime.

## Эксперимент (2026-10-04)

Эталон — стили Discogs для 1378 случайных релизов библиотеки (поиск по артисту и названию,
без сборников). 22 способа подсчёта. Отчёт: https://claude.ai/artifact/4zzNDpcJyD9Ey4BJ8H7baL

| способ | тегов | точность | полнота | 1-й тег верен |
|---|---|---|---|---|
| голосование треков (было в прототипе) | 3.2 | 33% | 57% | 52% |
| средняя ≥ 40% лучшего | 3.4 | 35% | 64% | 63% |
| средняя ≥ 25% лучшего, без ненадёжных стилей (**принято**) | 3.7 | 35% | 68% | 66% |
| калибровка по перцентилям стиля | 2–5 | 19–31% | 17–54% | 35–51% |

Выводы:

1. Калибровка «насколько стиль необычен для библиотеки» находит больше конкретных стилей, но
   подтверждается только 12–17% из них — хуже простого порога от лучшего тега.
2. Шум сидит в определённых стилях, а не в слабых оценках: Tech Trance показан на 203 релизах и
   подтверждён один раз, Bassline — 149 и один раз. Их список — `BLOCKED`.
3. Часть «ненадёжных» стилей — уточнения, которые Discogs не ставит, а ставит родителя: Halftime,
   Jungle, Breakcore → Drum n Bass; Schranz, Hard Techno, Deep Techno → Techno. Их список —
   `SUBSTYLE`: показываем только рядом с родителем. Эталоном это правило не проверить.
4. Правило «конкретный стиль вперёд общего» (прототип) роняло точность первого тега с 63% до 52%.

Точность занижена для всех способов одинаково: Discogs ставит в среднем 1.9 стиля.

## Методика

- **Релиз:** средняя оценка стиля по проанализированным трекам; стили ≥ 25% лучшего и ≥ 0.05,
  без `BLOCKED`, уточнения — только с родителем; до 5.
- **Лейбл / артист:** сколько релизов несут стиль (у артиста — релизы, где он основной);
  стили хотя бы у 5% релизов, до 10. Карточка лейбла: «588 релизов · Techno, Tech House».

## Открыто

- Делить ли `BLOCKED` / `SUBSTYLE` иначе — решение по таблице «Стили, которые Discogs не
  подтверждает» в отчёте.
- Фильтр релизов лейбла/артиста по клику на стиль.
- Общий стиль (Techno у Suara — 531 из 588) почти ничего не говорит на странице лейбла; можно
  засчитывать релиз только в 2–3 его первых стиля.
