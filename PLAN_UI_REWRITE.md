# UI Rewrite — Phased Plan

See `PLAN_UI_ARCHITECTURE.md` for architecture decisions, component map, and stack rationale.

## Available MCP servers

The following MCP servers are connected and should be actively used during execution:

- **shadcn** — look up shadcn/ui component APIs, props, and usage examples before adding or customising components
- **context7** — fetch up-to-date docs for React Router v7, TanStack Query, Zustand, Radix UI, Tailwind v4, Vite — use this instead of relying on training data, library APIs change
- **Playwright** — use in Phase 8 for E2E tests: player playback flow, page navigation, search

## Phase 2 — AudioEngine + Player store

**Goal:** music plays from the browser console, store is wired up.

- [ ] `engine/AudioEngine.ts`
  - Creates `HTMLAudioElement`, `preload="none"`
  - `load(url)`, `play()`, `pause()`, `seek(fraction)`, `setVolume(v)`, `setMuted(b)`
  - On `timeupdate` → `playerStore.setTime(currentTime, duration)`
  - On `ended` → `playerStore.handleTrackEnded()`
  - On `error` → `playerStore.setError(message)`
  - On `play` / `pause` → `playerStore.setPlaybackState(state)`
  - Media Session API: set metadata on play, register action handlers
- [ ] `store/playerStore.ts` (Zustand)
  - State: `session`, `queue`, `currentTrackId`, `currentQueueItemId`, `playbackState`, `currentTime`, `duration`, `volume`, `muted`, `error`, `expanded`
  - Actions: `playSource`, `playTrack`, `togglePlay`, `seek`, `skipNext`, `skipPrevious`, `toggleShuffle`, `toggleRepeatOne`, `toggleAutoplay`, `setAutoplayChip`, `setVolume`, `toggleMute`, `refreshQueue`, `recordEvent`, `handleTrackEnded`, `toggleExpanded`
  - Volume + mute persisted to localStorage on change
- [ ] `store/navidromeStore.ts` — liked track IDs set, `toggleLike(trackId)`, `fetchLikedIds()`

**Done when:** calling `playerStore.getState().playSource('artist', 1, 'Test')` in console plays music.

## Settled decisions

- **Routing:** React Router v7 loaders — data loads before render, no loading flash on navigation
- **Navidrome likes:** fetch on track change, cache in `navidromeStore` — no polling
- **Search:** 300ms debounce on input + Enter also triggers immediately
- **Styles:** Tailwind CSS v4 + shadcn/ui, theme variables mapped to discocs palette
- **Admin panel:** old UI moves to `/admin` with visible warning banner, no login required
- **Deployment:** separate containers — nginx (static + reverse proxy) + backend (FastAPI); no StaticFiles in FastAPI; all fetch calls use relative paths so no `VITE_API_BASE_URL` needed
